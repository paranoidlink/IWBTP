# I Wanna Be the Pepsi Can

A small platforming game project created in GameMaker.

The project was inspired by the difficult platforming style of *I Wanna Be the Guy* and was built as a personal GameMaker project.

## Project Contents

The repository contains the GameMaker project along with its supporting assets, including:

- Player and enemy sprites
- Platforms and moving platforms
- Spikes and other traps
- Checkpoints
- Power-ups
- Portals
- Multiple test and level rooms
- Game scripts

## Technologies

- GameMaker
- GML

## Notes

This is an older game development project and is preserved as part of my development history rather than as an actively maintained game.
